# PlaytimeGate

Плагин для **Paper 26.3** + **WorldGuard 7.0.x**: пока игрок не наиграл заданное время
(по умолчанию 24 часа), в приватах ему запрещены действия — ломать, ставить блоки,
открывать сундуки/двери, использовать кнопки, торговать с жителями, бить животных —
и он **не может создавать** приваты. Вход в приваты при этом **не** блокируется.

Когда порог набран, игрок получает доступ **ко всем** приватам WorldGuard
(включая собственные): плагин снимает отмены WorldGuard в таких регионах.

Все регионы, созданные игроками командой `/rg create` и аналогами, получают
стандартный шаблон флагов (по умолчанию `build: false, use: false, mob-damage: false`),
так что создаваемые приваты одинаковые.

Плюс две команды: `/playtime` (своё или чужое время) и `/ptop` (топ по наигранному времени).

Если установлен **TAB** (6.x, опциональная зависимость), плагин определяет AFK-игроков
и показывает у них в таб-листе префикс (по умолчанию `&8[AFK]&r`): регистрируется
плейсхолдер `%playtimegate-afk%`, который нужно добавить в формат таб-листа TAB.

---

## Требования

| Что | Версия |
|---|---|
| Сервер | Paper 26.3 (подойдёт и 26.2) |
| Java | 25+ (в проекте `--release 25`) |
| WorldGuard | 7.0.20+ (нужен и WorldEdit — он и так зависимость WG) |
| TAB | любая 6.x, опционально (привязка через рефлексию, не привязано к версии; без него плагин работает так же) |
| Сборка | JDK 25+, Gradle 8.5+ |

## Сборка

Проект — обычный Gradle-проект (Kotlin DSL), без shadow и лишних зависимостей:

```bash
gradle wrapper        # один раз, если нужен gradlew
./gradlew build       # Windows: gradlew.bat build
```

Готовый jar: `build/libs/PlaytimeGate-1.0.2.jar` → в `plugins/`.

Или просто откройте папку в IntelliJ IDEA как Gradle-проект и соберите `jar`.

> **Если javac ругается на версию class-файлов** (`class file has wrong version 69`),
> значит компиляция идёт под JDK младше 25 — соберите под JDK 25+
> (`options.release.set(25)` в `build.gradle.kts` уже стоит).

## Установка

1. `PlaytimeGate-1.0.2.jar` в `plugins/`.
2. Нужны установленные **WorldGuard** и **WorldEdit**.
3. Запустить сервер, при необходимости поправить `plugins/PlaytimeGate/config.yml`.
4. `/playtime reload` — применить изменения без перезапуска.

## Как это работает

1. Наигранное время берётся из ванильной статистики `minecraft:play_time`
   (`Statistic.PLAY_ONE_MINUTE`, тики / 20).
2. На каждое действие (ломание, установка, взаимодействие, урон по мобам,
   установка лодок/вагонеток) плагин смотрит регион WorldGuard в точке действия.
3. Если игрок «новичок» и точка попадает в приват, где он не владелец и не участник —
   действие отменяется и показывается сообщение (action bar или чат, с кулдауном).
4. Команды создания регионов (`/rg create`, `/rg define`, `/rg def`, `/rg d`, `/rg claim`
   и через алиасы `/region`, `/regions`) новичкам запрещаются с сообщанием
   `creation-denied`. У «взрослых» то же самое, но вместо запрета новый регион
   получает шаблонные флаги из `region-template` (WorldGuard создаёт регион
   асинхронно, поэтому шаблон ставится по опросу ~2 секунды).
5. Слушатели запрета стоят на `EventPriority.LOWEST` и срабатывают раньше WorldGuard,
   чтобы игрок увидел сообщение плагина, а не стандартное «You don't have permission».
   Слушатель-обход висит на `EventPriority.MONITOR` (после WorldGuard) и снимает
   отмену WG для игроков, наигравших порог, если точка в привате.
6. Права на создание (`worldguard.region.define`, `worldguard.region.wand`) выдаются
   всем игрокам через зарегистрированные Permission с `default: true`.
7. Регионы `__global__` и прочие служебные (`__*__`) игнорируются.
8. AFK-детекция: активная активность — ввод с клавиатуры, правый клик,
   инвентарь, чат, команды, взаимодействие с сущностями, полёт на элитре
   и собственный ход (на земле, без скорости/жидкости/транспорта, проверяется
   сэмплером раз в секунду). Левый клик (автокликер) и принудительное
   перемещение (поток воды, отброс, жемчужина, поршень, транспорт)
   активностью **не** считаются. Нет активности `afk.threshold-seconds` —
   игрок AFK; при смене состояния значение плейсхолдера обновляется
   мгновенно (`updateValue` через рефлексию), плюс авто-обновление TAB
   каждые 10 секунд. Игрок на экране смерти (dead) показывает
   `afk.dead-prefix`, приоритет выше AFK.

Что **не** делает плагин:

* не блокирует вход в приват (по выбранной логике — только действия);
* не трогает PvP — этим управляют флаги WorldGuard;
* не создаёт регион за игрока: только запрещает создание новичкам и докидывает
  шаблон флагов «взрослым»;
* не даёт игрокам прав управления регионами (`/rg remove`, `/rg flag ...` и т.д.) —
  на это нужны отдельные пермишны WorldGuard, по умолчанию они только у админа.

## Конфигурация (`config.yml`)

| Параметр | По умолчанию | Описание |
|---|---|---|
| `required-playtime` | `24h` | Порог. Форматы: `24h`, `90m`, `1d12h30m`, `3600s`. Число без буквы = **минуты** (`1440` = 24ч) |
| `exempt-own-regions` | `true` | Не ограничивать в своих приватах и там, где игрок member (в т.ч. через группу) |
| `exempt-regions` | `[]` | ID регионов-исключений (спавн, магазин, ивент-зона) |
| `exempt-worlds` | `[]` | Миры, где плагин не работает вообще |
| `block.physical-interactions` | `false` | Блокировать нажатие плит/растяжек |
| `block.entity-damage` | `true` | Блокировать урон по животным/жителям/стойкам |
| `region-template.enabled` | `true` | Применять шаблон флагов к новым регионам игроков |
| `region-template.flags` | `build: false, use: false, mob-damage: false` | Флаги, выставляемые каждому новому региону (значения `true`/`false`/строка) |
| `region-creation.enabled` | `true` | Выдавать всем игрокам права на создание регионов |
| `region-creation.permissions` | `worldguard.region.define`, `worldguard.region.wand` | Пермишны, выдаваемые всем (default: true) |
| `message.use-action-bar` | `true` | Сообщение в action bar вместо чата |
| `message.cooldown-seconds` | `5` | Антиспам на сообщения |
| `top.size` | `100` | Сколько игроков держать в кэше топа |
| `top.page-size` | `10` | Строк на страницу `/ptop` |
| `top.refresh-minutes` | `10` | Как часто пересобирать топ |
| `top.scan-batch-size` | `100` | Сколько игроков обрабатывать за тик (плавность сбора) |
| `afk.enabled` | `true` | Включить AFK-детекцию (без TAB работает, но не отображается) |
| `afk.threshold-seconds` | `300` | Через сколько секунд без активности игрок считается AFK |
| `afk.tab-prefix` | `&8[AFK]&r ` | Префикс в табе у AFK-игрока (цветовые коды `&`) |
| `afk.dead-prefix` | `&4[СМЕРТЬ]&r ` | Префикс в табе у игрока на экране смерти |

Все сообщения — в секции `messages`, с кодами `&` и плейсхолдерами
`{prefix}`, `{player}`, `{played}`, `{required}`, `{left}`, `{status}`, `{hint}`,
`{position}`, `{page}`, `{pages}`, `{total}`. Сообщение можно задать строкой или списком строк.

## Команды и права

| Команда | Что делает | Право (по умолчанию) |
|---|---|---|
| `/playtime`, `/pt` | Своё время, статус приватов, остаток до открытия | `playtimegate.use` (все) |
| `/playtime <ник>` | Время другого игрока (в т.ч. оффлайн) | `playtimegate.others` (op) |
| `/playtime reload` | Перечитать `config.yml` | `playtimegate.reload` (op) |
| `/ptop [стр.]` | Топ по наигранному времени | `playtimegate.top` (все) |
| `/rg create ...` и аналоги | Создание привата (новичкам запрещено, «взрослым» — шаблон) | `worldguard.region.define` + `worldguard.region.wand` (выдаются всем плагином) |
| — | Обход ограничения приватов (в т.ч. обход WG через MONITOR-обход) | `playtimegate.bypass` (op) |

> **Нюанс с wepif:** WorldGuard проверяет пермишны через `PermissionsResolverManager`.
> Если на сервере **нет** пермишн-плагина и **нет** `wepif.yml` — работает стандартный
> Bukkit-механизм, и права из `region-creation.permissions` выдаются корректно.
> Если сервер использует только `wepif.yml` (без LuckPerms/Vault/PE) — WorldGuard
> читает права только из `wepif.yml`, и тогда добавьте туда `worldguard.region.define: true`
> (и `worldguard.region.wand: true`). С LuckPerms/Vault/Essentials всё работает как есть.

## Как собирается топ

`/ptop` не читает файлы на каждый запрос: при старте и раз в `top.refresh-minutes`
плагин порциями по `top.scan-batch-size` за тик проходит по `Bukkit.getOfflinePlayers()`
и кэширует время. Сортировка и срез — в памяти. Поэтому топ включает и оффлайн-игроков,
но на очень больших серверах (десятки тысяч уникальных игроков) первая сборка занимает
несколько секунд — это нормально и не нагружает TPS рывками.

## Известные ограничения

* AFK-время учитывается (ванильная статистика не различает AFK и активную игру).
* AFK-статус не сохраняется: оффлайн-игроки не афки, состояние живёт в памяти.
* AFK-детекция не идеальна: бот с автокликером **и** авто-ходом (движение
  без клавиатуры) будет считаться активным; стоящий в лодке без гребли
  (без клавиатуры) — афком (это и правда афк).
* Привязка к TAB идёт через рефлексию — плагин не скомпилирован против
  конкретного jar TAB и работает с любой совместимой версией 6.x.
* Порог общий для всех; разные пороги по группам не реализованы — можно сделать
  отдельным правом-исключением или вторым порогом, если понадобится.
* MONITOR-обход снимает отмену **любого** отменённого события в привате у
  «взрослого» игрока — если другой плагин отменил действие по своей причине,
  плагин тоже его откатит в приватной зоне.
* Шаблон флагов применяется ко всем регионам, созданным игроками через команды
  (в т.ч. админами в игре); регионы, созданные с консоли, шаблон не получают.
* Folia не поддерживается (используется классический планировщик Bukkit).
* Если сервер не принимает `api-version: '1.21'` в `plugin.yml` — замените на `'26.3'`.
